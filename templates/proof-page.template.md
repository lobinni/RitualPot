# Proof page template

Publish this at an `https://` URL and submit that URL with `prove`. The contract freezes the whole
page on chain when you submit it, and validators judge only that frozen text - editing the live
page afterwards changes nothing.

Keep the page under 1200 characters. A longer page is refused, so that every validator can read all
of it.

---

**Period:** _which period of the pot this page covers_

**What was done:** _the concrete action, with numbers: distance, count, duration, pages, sessions_

**When:** _date and time window in UTC_

**How it can be checked:** _where the raw record lives (log, export, screenshot link) and what a
reader should look at_

**Notes:** _anything a judge would otherwise have to guess_

---

Guidance:

- State facts that are on this page. A claim without a number is hard to rule as met.
- Do not address the validators or the model inside the page. Instruction-like phrasing is flagged
  and stored with every ruling round, and it counts against you.
- One page per period. A period without a proof is lost.
